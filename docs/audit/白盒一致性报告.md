> 审计日期：2026-10-27

## 一、总判定

**不是 1:1。** 395 项判定中：

| 判定 | 数量 | 占比 |
|------|------|------|
| 一致（逻辑逐指令级吻合） | 104 | ~26% |
| 等价（实现不同但行为相同） | 107 | ~27% |
| **偏差（行为不同）** | **86** | **~22%** |
| **桩（未实现/空实现）** | **56** | **~14%** |

即：**约 47% 的表面积与原版行为不一致**。已验证为"真一致"的是：Input 的 press?/trigger?/repeat? 帧语义与连发计数、像素格式 ARGB8888、get_pixel 越界语义、两阶段注册顺序、内嵌 RPG 源码（与原版 DLL 逐字节相等）、导出表 69 名 1:1。

## 三、高危偏差（必须在"1:1"主张成立前修复）

### 存档/数据损毁级
1. **Table `_dump`/`_load` 头格式与原版不符**（A1-D3/D3b）。原版头 = `[argc, x, y, z, 元素数]`（0x1000ec41–0x1000ec5b），元素为 int16 LE；重建头 = `[x, y, z, n, n]` 文本序列化。**读原版存档必错位**——这直接违反已升为硬门槛的"原版存档→重建可读"。
2. **Color/Tone/Rect 的 `_dump`/`_load` 同为文本格式**，原版为 32B IEEE754 double / 16B int32 二进制（0x10010041 / 0x1000c651）。Marshal 兼容全破。
3. **五类数据类 + Bitmap 的 `initialize_copy` 全部缺失**（原版 0x100065a0 等五处均有完整拷贝+类型检查）：dup/clone 回退 Object#dup，Table 数据不复制，Bitmap 克隆产物不可用。Tilemap/Window/Plane/Sprite/Viewport 的 clone/dup 同样未覆盖——而 Ruby 默认 clone 会共享 DATA_PTR，有 double-free 风险（A4）。

### 输入正确性级
4. **Input A/C 键映射与原版交换**（A5 偏差1）。原版：A(11)=VK_SHIFT、C(13)=Z/Enter/Space、物理 C 键显式废弃（0x10013b4f 写槽 0）；重建：A='Z'、C='C'，Shift→A 缺失。**这就是黑盒测试观察到的"按键串扰"的根因**。
5. 对角迟滞缺失（CInput+0x9c，0x10013dcf）+ dir4 冲突序不符（0x10013d65 末写覆盖 down>right>up>left vs 重建竖直优先）：斜向移动的 dir4/dir8 序列与原版不同。
6. 连发键扫描 tie-break 相反（原版最后新键胜，重建取第一个）；B 键缺 NUMPAD0/INSERT；手柄 joyGetPosEx 全套（0x10013510）未实现。

### 渲染完整性级
7. **自动图块 48 形状→2x3 片映射表未还原**（A4）。本次已在原版汇编中**完整定位并逐字节提取**三张 48×8 表：T1=0x10104df8（A1）、T2=0x10104f78（A2）、T3=0x101050f8（A3），查表代码在绘制函数 0x100172e0（shape×8 行选、象限取片、16px 半片粒度、`call 0x10096680` 子块绘制、`cmp eax,4` 循环）。A2 墙格式列展开路径、水面半格 +8px 特例（0x10017706/0x10017776）、piece5 均缺失。**与黑盒 98.83% 地图差异直接对应**。
8. **渲染管线结构性缺失**（A3/A4）：合成完全忽略 viewport（裁剪/层次/色叠加/色调）；Plane 完全不参与合成；无 z 排序（按创建序画）；angle/mirror/bush/wave/color/tone/flash 属性有存储无渲染；Tilemap A1 水波动画（0x10016d50）未实现。
9. **Graphics 全家**（A3）：brightness= 存值但渲染从不使用；snap_to_bitmap 返回空白图；resize_screen 不改后缓冲；frame_reset 语义相反（原版只重置计时基线，重建清零 frame_count）；_reset 多清 frame_count；frame_rate= 缺 [10,120] 钳制。

### 语义偏差级（玩家可感知）
10. Color/Tone 全部 setter 无 [0,255] 钳制（原版三分支钳制 0x100063e5）；alpha 缺省 255 vs 原版 0.0（A1-D13 待运行时复核）。
11. Sprite.color 默认 (0,0,0,**255**)，原版 (0,0,0,**0**)（0x1000d920）——合成结果会整体不同。
12. Sprite.src_rect=/Viewport.rect= 直接替换引用，原版是值拷贝进内部同一 Rect + observer 回写（0x1000cf20）——脚本对 rect 的后续 set() 不再影响 sprite。
13. getter 类型：原版 x/y/z/ox/oy 等全部返回 Fixnum（0x1001d850），重建多处返回 Float——`==` 比较在 Ruby 里碰巧兼容，但 Marshal/inspect/脚本类型判断会露馅。
14. dispose 后语义：原版所有访问器 raise RGSSError("disposed sprite")，重建照常工作；Window dispose 后仍被绘制（未注销 g_windows）。
15. Window.initialize 预创建 contents/cursor_rect，原版初值 nil（破坏 `contents.nil?` 脚本语义）；back_opacity 初值 192 vs 原版 255（0x10019940 四个不透明度全 0xff）。
16. Sprite/Viewport clone/dup：原版无条件 raise "can't clone %s"（0x10008fb0），重建可克隆。
17. Graphics.fadein/fadeout 为空桩（原版逐帧亮度渐变+每帧完整 update，0x10007e30/0x10007ef0）；freeze 只置标记不做真快照。
18. Bitmap：initialize 加载失败建 1x1 空图 vs 原版抛 "failed to create bitmap"（0x10103E88）；stretch_blt 丢弃 opacity 参数；fill_rect/clear_rect/gradient_fill_rect 缺 Rect 单参形态；hue_change/blur/radial_blur 三桩。

## 六、无法验证项（诚实清单）

- 原版数据段的钳制常量/格式串是加密的（A1 11 项）：Color/Tone 边界常量实际数值、to_s 格式、Font ivar 文本需运行时 dump 复核。
- 原生像素核心内部数学（blt 插值、hue/blur 算法）只核对了入口约定与模式分发（A2）。
- Sprite zoom/angle/wave 的逐指令 setter 与默认值（A3 6 项）。
- Window 九宫格逐像素渲染等价性：结构级一致已证实，像素级需渲染对拍（A4）。

## 七、修复优先级建议（给开发会话）

1. **P0 数据兼容**：Table/Color/Tone/Rect 的 `_dump`/`_load` 改二进制格式（A1 已给全部常量与地址）；initialize_copy 五连。
2. **P0 输入**：A/C 映射交换修复 + Shift→A + 物理C废弃 + 对角迟滞 + dir4 覆盖序（A5 有逐键对照表）。
3. **P0 渲染**：照抄 A4 专项1 的三张 48×8 表还原 autotile；z 排序 + Plane 入管线。
4. **P1**：viewport 裁剪/色调、Sprite.color 默认值、src_rect 值拷贝、dispose 异常、钳制系列、Graphics 六项。
5. **P2**：clone/dup raise、p/print/undef、save_data arity、SetupRTP、$TEST、F12 Reset 活代码、Audio。

## 3. RGSSGameMain 还原（与 VX 同构，跨版本印证）

```
RGSSGameMain(a, b, c):                        # 0x3B90
    local = 0
    r = getenv_like("$DEBUG", &local)          # 串 @0x100E75A0 = "$DEBUG"
    g_test_flag = (r == 2)                     # @0x1012B6C0
    game = operator new(0x160)                 # CGameFrame，XP 大小 0x160
    game->CGameFrame::ctor()                   # 0x10002430
    g_game = game                              # @0x1012B6C4
    ret = game->Run(a, b, c)                   # 0x100031A0（thiscall）
    if (g_game) g_game->vtable[0](1)           # 虚析构（其余 Singleton 同型）
    return ret
```
**VX 202E 同结构**：`$TEST` 判定 → `new CGameFrame(0x26C)` → `Run(a,b,c)` → 虚析构。
差异仅：环境变量名（XP `$DEBUG` / VX `$TEST`）、CGameFrame 大小、全局地址。

## 4. RTP 与路径语义（第三方改动终裁依据）

- `RGSSGetPathWithRTP(1 参字符串)` 0x3D10：StrLen 校验（空 或 ≥0x104 走退化分支）→ 两个 0x400 栈缓冲 →
  **MultiByteToWideChar / WideCharToMultiByte**（IAT 0xE7210/0xE720C）做字符集转换 → 拼接。
- `RGSSSetupRTP` 0x4320：**RegOpenKeyExA(HKLM, "Software\Enterbrain\RGSS\RTP")**（槽 0xE7010）
  + **GetPrivateProfileStringA**（槽 0xE7158）读 `[Game]` 节（串 @0xE75AC "Game"）的 **"RTP%d"** 键
  （串 @0xE75B4，i=1,2,3；wsprintfA 槽 0xE7384 组键名）→ 填充 RTP 路径栈。

**终裁：《103J 第三方改动清单》= 无第三方功能补丁。**
RTP 解析链**经 Hex-Rays 完整反编译确认**（`RGSSSetupRTP` 全函数）：
读 Game.ini `[Game]` 节 `RTP1..RTP9`（wsprintfA 组键名）→ 逐个查 HKLM 注册表
`Software\Enterbrain\RGSS\RTP`（RegQueryValueExA，须 REG_SZ）→ 去尾反斜杠 →
`RGSSAddRTPPath`。逻辑完整无改动；导入集差异纯属 CRT 演化（M1 §6）。
103J = 官方 1.03 代码 + UPX 重打包壳（壳不还原，按共识）。

附带实证：`RGSSGameMain` 的 `$DEBUG==2` 判定即对 Ruby 全局 `$DEBUG` 求值
（`sub_10031DC0` = RGSSEval 同款求值器）——测试模式经由 Ruby 全局变量，非 getenv。

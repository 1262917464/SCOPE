## 1. 主循环：两层循环 + 两张跳转表

`TFormLcfGameMain.AuroraDrawMain`（2000: `0x49C598`，2003: `0x4902A8`，Steam: `0x4C94EC`）
是整台引擎的心跳。它挂到 `TAuroraDraw` 的 `+0x98`（见 §4），由 Windows 消息循环反复调用。

结构不是"一帧一跳"，而是**外层无限循环套内层场景分发**：

```
AuroraDrawMain(self):                     ; eax = Self
  helper_49C218(self)                     ; 一次性初始化（图形/输入/场景）
loop:
  if ($TEST && state[+4] != 2) {           ; 测试模式快速路径
      helper_43F908(self); goto out;      ; 直接跳到 0x49C7AA 返回
  }
  prev = state[+4]                        ; 场景索引快照
  state[+8]++                             ; 帧计数自增
  game->something()                       ; 0x457520

  switch (state[+4]) {                    ; ★ 第一张跳转表 @0x49C5FB
      0: Scenes[0]->Execute()             ; 0x4806B8
      1: Scenes[1]->Execute()             ; 0x47F9F0
      2: Scenes[2]->Execute()             ; 0x478DE8
      3: Scenes[3]->Execute()             ; 0x476EB0
      4: Scenes[4]->Execute()             ; 0x475248
      5: Scenes[5]->Execute()             ; 0x473CCC
      6: Scenes[6]->Execute()             ; 0x4732C0
      7: Scenes[7]->Execute()             ; 0x472D34
      8: Scenes[8]->Execute()             ; 0x4725C0
  }

  if (state[+4] != prev) goto loop        ; 场景刚切换 → 立刻重跑，不绘制不等待

  elapsed = self->GetElapsedFrames()      ; 0x4557F4
  if (elapsed >= frame_skip_div/2)        ; 0x49C6B7: sar edx,1 → /2
      goto draw_or_skip
  if (state[+4] != 0 || !Scenes[0]->flag1C)
      goto draw_or_skip

  switch (state[+4]) {                    ; ★ 第二张跳转表 @0x49C6F5
      0..8: Scenes[i]->vmt[+8]()          ; 虚调用，纯绘制
  }

draw_or_skip:
  self->last_tick = GetTickCount()        ; 0x4561D8
  self->accum     = 0
  self->WaitFrame()                       ; 0x4562EC
  goto loop
```

**两张跳转表的语义区分**是 M2 最重要的发现：
- **第一张**（`0x49C5FB`）走具体函数地址，是**场景逻辑更新**；
- **第二张**（`0x49C6F5`）走 `[vmt+8]` 虚调用，是**每帧绘制**。

两者都由同一个 `state[+4]` 分发，所以"场景索引"是全局唯一的状态源。

## 2. 九个场景槽

场景对象存在 BSS 里的 9 个连续槽，通过 DATA 段的一张指针表间接访问：

| case | 全局符号（2000） | 实际槽 | 处理函数 |
|------|-----------------|--------|----------|
| 0 | `0x49FB38` → `0x4A2B04` | Field | `0x4806B8` |
| 1 | `0x49FB70` → `0x4A2B08` | Menu | `0x47F9F0` |
| 2 | `0x49FC44` → `0x4A2B0C` | Battle | `0x478DE8` |
| 3 | `0x49FD40` → `0x4A2B10` | Shop | `0x476EB0` |
| 4 | `0x49FB10` → `0x4A2B14` | Name | `0x475248` |
| 5 | `0x49FE90` → `0x4A2B18` | SaveFile | `0x473CCC` |
| 6 | `0x49FAB0` → `0x4A2B1C` | Title | `0x4732C0` |
| 7 | `0x49FEBC` → `0x4A2B20` | GameOver | `0x472D34` |
| 8 | `0x49FC58` → `0x4A2B24` | Debug | `0x4725C0` |

每个场景处理器都呈**同一套模板**（这是 Delphi 类方法的典型形状）：

```
SceneX_Execute(self):                     ; eax = Self
  if (self->initialized(+0xC) == 0)       ; 懒初始化
      SceneX_Init(self)
  switch (self->state(+0xC 或 +0xD))      ; 各自的子状态机
  ...
```

`TLcfScene` 基类实例 12 字节，子类保留 `+0xC` 作为 `initialized`、`+0xD` 作为 `update flag`。

## 3. 帧率与常量

从 `TAuroraDraw.Create`（`0x454D24`）直接读出：

| 字段 | 值 | 汇编来源 |
|------|-----|----------|
| `+0xC0` frame_rate | **0x14 = 20** | `mov dword [ebx+0xC0], 0x14` |
| `+0xC4` frame_skip_div | **4** | `mov dword [ebx+0xC4], 4` |
| `+0xB8` frame_interval | **1000.0 / 20** | `fild` + `fdivr [0x454E1C]`，该常量 = `1000.0f` |
| `+0xAC` base_tick | `GetTickCount()` | `call 0x447774` |
| 窗口尺寸 | **320 × 240** | `mov ecx,0xF0` / `mov edx,0x140` |

`0x447774` 是 `GetTickCount` 的内部包装（被 `0x45619C` 调用后减去 `+0xAC` 基准）。

**帧间隔算法**（`0x4557F4`）：

```
result = (GetTickCount() - base_tick - accum * frame_interval) / frame_interval
```

原版是 double 运算后 `Round`（`0x4029D0`），返回整数帧数。

## 4. 启动链

```
TFormLcfGameMain.FormCreate                    (0x49BCC0)
  → TAuroraDraw.Create(True)                   (0x454D24)
      +0xAC := GetTickCount()
      +0xC4 := 4
      +0xC0 := 20
      +0xB8 := 1000.0 / 20
      → 创建主表面 320x240                      (0x452808)
      → 安装 WndProc 0x4550A4 到 form+0x280
        (form+0x284 = TAuroraDraw 自身)
  → draw->+0x9C := 窗体自身
  → draw->+0x98 := 0x49C598 (AuroraDrawMain)   ★ 主循环挂接点
  → 解析命令行开关
```

命令行开关（`FormCreate` 里逐个 `ParamStr` + `CompareText`）：

| 参数序号 | 开关 | 全局 |
|---------|------|------|
| 1 | `BattleTest` | `$BTEST` |
| 1 | `TestPlay` | `$TESTPLAY` |
| 2 | `HideTitle` | `$HIDE_TITLE` |
| 3 | `Window` | 窗口化 |

`$TEST := not $TESTPLAY`，`$BTEST := $TESTPLAY or $BTEST`。

`FormCloseQuery` / `FormDestroy` 通过同一批全局单例做清理，顺序与创建相反。

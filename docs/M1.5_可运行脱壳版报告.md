# M1.5 报告 — 可运行的脱壳 RGSS202E.dll

日期：2026-10-26 ｜ 前置：M1（分析版 PE）

## 产物

- `unpacked/RGSS202E_probe.dll` — **可运行版**（部署需搭配 `tools/rgssprobe.dll`）
- `unpacked/RGSS202E_runnable.dll` — 同上但两个槽为占位（暂不可用，见 §4）
- `unpacked/RGSS202E_pristine/` — 纯净内存 dump（OEP 处快照）+ 模块/导出映射

## 验证结果

1. LoadLibrary 冒烟：加载成功（基址 0x10000000），69 个导出 GetProcAddress 全部命中，卸载干净。
2. **真实游戏**：Project3（测试副本）配 `RGSS202E_probe.dll`（改名 RGSS202E.dll）+ rgssprobe.dll，
   Game.exe 正常启动，主窗口标题 "Project3"，运行 10 秒无崩溃。

## 关键技术过程（踩坑记录）

### 1. OEP 定位
ASPack stub 尾部 `ret 0xC; push 0x100E6E94; ret` → **OEP = RVA 0xE6E94**（MSVC DllMainCRTStartup，
入口特征 `cmp [esp+8],1; jne; call`）。文件态 imm 为 0（stub 运行时写入），静态 patch 不可行。

### 2. 导入表重建（mkpe2.py）
- IAT 扫描（≥2 连续同模块指针段）+ 导入区内单槽回收 → **259 个导入、16 组描述符**；
- 标准格式：OFT(hint/name 或序号) + FT 指向原位 IAT 槽 + OFT NULL 终止项（曾因漏写终止项导致
  加载器把 "comc"/"gdi3" 字符串当 RVA，报 126）；
- **转发导出（FWD）解析**：dump 时解析 "NTDLL.Func" 转发串，导入改指真身模块
  （kernel32!Rtl* → ntdll，user32!DefWindowProcW → ntdll!NtdllDefWindowProc_W）。

### 3. 脏 .data 问题（本项目最大坑）
首版 dump 取自"原版 DllMain 跑完之后"，.data 全是运行期状态（旧进程堆指针等），
重启 CRT init 时 `InterlockedIncrement(旧堆指针)` 直接 AV。
**解法**：调试器方案（unpacker3.c）——父进程 DEBUG_PROCESS 派生子进程加载壳 DLL，
LOAD_DLL 事件时在 OEP 下 DR0 硬件执行断点，断点命中即 stub 解压完成、原 DllMain 未执行，
此刻由独立 Python 进程（dumpat.py, ctypes）转储 → 纯净镜像。
注意硬件断点命中时 EIP==OEP（非 INT3 的 +1），且命中后不得 ContinueDebugEvent（冻结子进程转储）。

### 4. 遗留：两个 apphelp 污染槽
本机 Win11 对 32 位进程必注入 apphelp（manifest/supportedOS 无效），ASPack stub 解析
user32 导入时两个函数拿到 shim 包装函数（非真身）：
- 槽 0xFF2DC：调用点 rva 0x1571/0x15BE/0xBC6FF，4 参数含 RECT 结构指针与常量 0x30
- 槽 0xFF324：调用点 rva 0x9777A/0x97C95，1-2 参数（疑似 hwnd）
两者运行期由 `rgssprobe.dll` 探针顶替（no-op，保留寄存器），游戏实测 10 秒内未被调用。
**定名工作移交 M2**：结合调用点语义反推 + 更长时间的游戏会话采集。

## 工具清单（tools/）

| 文件 | 作用 |
|------|------|
| unpacker.c/.exe | v1：进程内 LoadLibrary 后 dump（分析用，.data 脏） |
| unpacker2.c | v2：patch 交接指令方案（因 stub 自写 imm 而废弃） |
| unpacker3.c/.exe | v3：调试器+硬件断点，冻结于 OEP，调 dumpat.py 转储（**主力**） |
| dumpat.py | ctypes 外部转储：镜像+模块+导出映射（含 FWD/序号） |
| mkpe.py | 分析版 PE（给 IDA，导入为标注形式） |
| mkpe2.py | 可运行版 PE（标准导入表，--probe 模式接探针） |
| probe.S + probelog.c + probe.def → rgssprobe.dll | 运行期导入探针 |
| smoke.c/.exe | LoadLibrary 冒烟+异常链转储 |
| impcheck.c/.exe | 逐项验证导入可解析性 |

## 复现流水线

```
unpacker3.exe backup\RGSS202E.dll unpacked\RGSS202E_pristine E6E94
copy v1 的 modules.txt/modmaps.txt → pristine 目录（同 boot 基址一致）
py mkpe2.py unpacked\RGSS202E_pristine unpacked\RGSS202E_probe.dll 0xE6E94 --probe
impcheck → smoke → 游戏实测
```

# M1 报告 — 脱壳、资产清单与工具链验证

日期：2026-10-26 ｜ 目标：RGSS202E.dll（VX 系列 2010-09-02 版，861,696 字节，ASPack 壳）

## 1. 脱壳（tools/unpacker.c + tools/mkpe.py）

- 自写 32 位 loader（mingw32 gcc 12.2 编译）：`LoadLibrary` 加载壳 DLL → ASPack stub 在
  DllMain 内完成解压与导入解析 → 直接 dump 内存镜像。
- 基址命中默认值 0x10000000，dump 大小 0x203000（2,109,440 字节）。
- `mkpe.py` 把 dump 组装回可分析 PE：
  - 文件布局 offset==RVA，13 节（12 原始节 + 合成的 `.imp2` 导入重建节）；
  - IAT 重建：按"连续同模块导出地址指针段"扫描出 13 组 thunk 数组，合成
    IMAGE_IMPORT_DESCRIPTOR 指向原位 IAT；
  - 产物：`unpacked/RGSS202E_unpacked.dll`（SHA-256 bd3dd382…7049）。
- 旧空 IDA 库（.id0 等）已挪至 `backup/ida_old_empty_db/`（后发现已被 IDA 自动清理，未留残骸）。

## 2. 关键鉴定结论

| 项 | 结论 | 证据 |
|----|------|------|
| Ruby 版本 | **1.8.1**（官方 MRI） | dump 内 "1.8.1" 版本串、RUBY_VERSION 串、regex_* 导出集合与 1.8 regex.c 吻合 |
| 编译器 | MSVC，**带完整 RTTI** | `CGameFrame::`vftable'` 等类名在反编译中直接恢复 |
| 图形后端 | **纯 GDI（无 DirectX）** | 导入表只有 gdi32（CreateDIBSection/BitBlt…），加载后模块表无 d3d*/ddraw/dsound/dinput |
| 音频后端 | winmm（MCI + mmio）+ msacm32（ACM 流式解码） | 导入清单 |
| 输入 | user32 消息 + winmm joyGetPosEx（手柄） | 导入清单 |
| 壳 | ASPack（.aspack/.adata 节），入口 RVA 0x200001 | 节表 |
| 其他 | zlib 疑似 1.2.3 内置；ws2_32 有 8 个导入（用途待查，M2） | 字符串/导入表 |

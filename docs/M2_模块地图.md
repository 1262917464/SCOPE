# M2 — 模块地图（RVA 区段 → 归属）

> 依据：RTTI 扫描（tools/rtti_scan.py，47 TypeDescriptor / 45 COL / 45 vftable）、
> 导出地址、字符串区、调用点聚类。区段号 = 脱壳 PE 节表。

## 1. 三层架构（M2 核心结论）

```
┌───────────────────────────────────────────────────┐
│ RGSS API 层 (导出 69 个, RVA 0x27F0–0x3350)        │  Game.exe 契约
├───────────────────────────────────────────────────┤
│ CGameFrame 主控 (0x26C 字节单例)                    │  游戏主循环/窗口/帧调度
│  └─ CRx* 对象层 (Ruby 绑定): RxSprite/RxPlane/     │  每个对应一个 Ruby 类
│     RxTilemap/RxTilemapSprite/RxViewport/RxWindow/ │
│     RxSurface/RxInput/RxFontList/RxMemoryFile      │
├───────────────────────────────────────────────────┤
│ NxDrawLocal 2D 库: NxScreen/NxWindow/NxSprite/     │  GDI+DIB 渲染
│  NxSurfaceSprite/NxSurface/NxCustomDraw8/32/       │  8/32bpp 双实现
│  NxDynamicDraw8/32/NxDIBImage(+Loader BMP/PNG/JPEG)│  + 图片解码
├───────────────────────────────────────────────────┤
│ CSx* 音频: CSxAudio/CSxDirectSound(COM 动态加载)/  │  DirectSound + MCI
│  CSxAudioSegment/SoundBuffer{Static,Stream}/       │  WAV / ACM / Ogg
│  CSxWaveReader/CSxAcmWavFileReader/CSxOggFileReader│  三路读取器
├───────────────────────────────────────────────────┤
│ Ruby 1.8.1 解释器 (MRI, 含 regex.c/re.c)           │  M3 官方源码替换
└───────────────────────────────────────────────────┘
```

## 4. 第三方组件鉴定（M2 结案）

| 组件 | 版本 | 证据 |
|------|------|------|
| zlib | **1.2.3** | "deflate 1.2.3 Copyright 1995-2005 Jean-loup Gailly" / "inflate 1.2.3 …Mark Adler" |
| libpng | **1.2.16** | "1.2.16" @0x14419C + libpng 错误串 ×10 |
| JPEG 解码器 | 版本串 "2.0.8"（具体库待 M4 定名） | "JPEG" ×24 |
| Ogg/Vorbis | 内置解码器（版本串 0.6.0 待对号） | "OggS"/"vorbis" @0x146308；CSxOggFileReader |
| **ws2_32（8 导入）** | **Ruby 1.8 线程调度器依赖，非网络功能** | 调用点仅 RVA 0x8D700–0x8FA00 一处（select/WSAGetLastError/closesocket/setsockopt），无 socket/connect/bind —— Ruby 1.8 thread.c 的 select-sleep 模式 |

## 5. zlib 用途推断（待 M4 证实）

Scripts.rvdata / .rvdata 存档为 Marshal 格式非压缩；zlib 最可能用于：
(a) RGSS 内部 `Zlib` Ruby 模块暴露（RGSS2 提供 Zlib 模块给脚本）→ M4 查 Ruby 侧绑定；
(b) PNG 解码路径（libpng 本身不依赖外部 zlib 时常内置 inflate）。
